
# RecoverAI

A multimodal GenAI-powered recovery companion platform.

## Architecture

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- FastAPI
- PostgreSQL
- Redis
- pgvector

AI:
- OpenAI APIs
- Voice processing
- Long-term memory
- Risk prediction


## Structure

web/
    User application

caregiver-dashboard/
    Caregiver portal

backend/
    AI and API services

database/
    Data layer

ai/
    Prompts and AI logic
